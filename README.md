# TargSys Landing Page

A responsive, Armenian-first landing page for TargSys, an IT services company based in Yerevan, Armenia.

The site presents TargSys as a technology partner for businesses that need reliable infrastructure, technical support, communications, security systems, and specialist training.

## Features

- Responsive single-page landing experience
- Armenian-first content and navigation
- Hero section with local TargSys imagery
- Company overview and capability summary
- Service cards for network systems, telephone complexes, IT support, and security
- Interactive service filtering by category:
  - All
  - Infrastructure (network systems, telephone complexes)
  - Support (IT support)
  - Security (security systems)
- Expandable "Read more" block in the About section
- Subscription IT support section
- Responsive trusted-partner logo carousel
- IT training section
- Contact details with phone and email links
- Google Maps embed for the Yerevan office location
- Dynamic copyright year generated by JavaScript
- Mobile navigation menu
- Email copy-to-clipboard action
- Scroll-reveal animations
- Responsive layouts tested from 250px mobile widths through desktop screens

## Project Structure

```text
.
├── index.html       # Page structure and content
├── style.css        # Layout, colors, responsive styles, and animations
├── script.js        # Navigation, filters, carousel, dynamic year, and UI behavior
└── assets/          # Images used by the landing page
```

## Run Locally

The page should be served over HTTP instead of opened directly with a `file:///` URL. This avoids browser security restrictions around local files, anchors, and embedded content such as Google Maps.

From the project directory, run:

```bash
python -m http.server 5500
```

Open the site at:

```text
http://localhost:5500/index.html
```

No package installation or build step is required.

## Main Sections

### Hero

Introduces TargSys and directs visitors to the services and contact sections.

### About

Explains the company’s role in the Armenian IT sector and summarizes its core capabilities.

### Services

Displays the four primary service categories. The filter buttons are powered by `script.js` and update the visible service cards without reloading the page.

### Subscription Support

Describes recurring IT support, preventive checks, remote management, and rapid problem resolution.

### Trusted Partners

Displays the recovered partner logos in a responsive carousel. The carousel groups logos according to viewport width:

- Desktop: 10 logos per slide
- Tablet: 6 logos per slide
- Small mobile: 4 logos per slide

### Training

Presents TargSys professional training for students and beginning IT specialists.

### Contact

Includes the office address, phone numbers, email address, social links, and an embedded Google Map.

## Deployment

This is a static website and can be deployed to any host that serves HTML, CSS, JavaScript, and image files, including:

- GitHub Pages
- Netlify
- Vercel static hosting
- Cloudflare Pages
- Traditional web hosting

Upload the complete project structure and keep the relative paths between `index.html`, `style.css`, `script.js`, and `assets/` unchanged.

## Maintenance Notes

- Add or replace page content in `index.html`.
- Update layout and responsive behavior in `style.css`.
- Update interactions in `script.js`.
- Add new images to `assets/` and reference them with relative paths.
- Keep image filenames URL-safe when adding new assets.
- Test at desktop, tablet, 390px mobile, and 250px narrow mobile widths after significant changes.
